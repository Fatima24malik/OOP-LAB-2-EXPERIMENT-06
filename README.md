# Bank Management System

A simple Java Object-Oriented Programming project that simulates basic banking operations such as deposits, withdrawals, and account management.

## Features

- Create a bank account
- Deposit money
- Withdraw money
- Display account details
- Balance validation

## OOP Concepts Used

- Classes and Objects
- Encapsulation
- Constructors
- Methods

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## How to Run

### Compile

```bash
javac Main.java
```

### Execute

```bash
java Main
```
